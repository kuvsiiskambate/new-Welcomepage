# 7Arts - Streaming Platform Welcome Page

Уелкъм страница за 7Arts - платформа за културно и артхаус съдържание.

## 📁 Структура на проекта

```
new-Welcomepage/
├── index.html          # Основен HTML файл
├── styles.css          # CSS стилове
├── script.js           # JavaScript функционалност
└── README.md           # Документация
```

## 🎨 Характеристики

- **Респонсивен дизайн** - оптимизиран за всички устройства
- **Модерен UI** - тъмна тема с неонови сини акценти
- **Интерактивни елементи** - FAQ акордеон, hover ефекти
- **Плавна анимация** - fade-in ефекти при скролване
- **Semantic HTML5** - чист и структуриран код

## 📋 Секции

1. **Hero Section** - 7Arts лого с филмови плакати на фона
2. **Абонаментни планове** - месечен, тримесечен и годишен
3. **Културно развлечение** - категории и филмова колекция
4. **Live секция** - информация за преки предавания
5. **Ексклузивни заглавия** - промоция на премиерни филми
6. **Всички устройства** - съвместимост с различни платформи
7. **Кан селекция** - награждавани филми
8. **Литературата в киното** - адаптации на книги
9. **FAQ** - често задавани въпроси
10. **Footer** - линкове и информация

## 🚀 Стартиране

Просто отворете `index.html` във вашия браузър:

```bash
open index.html
```

Или стартирайте локален сървър:

```bash
# С Python 3
python -m http.server 8000

# С Node.js
npx serve

# С PHP
php -S localhost:8000
```

## 🎯 JavaScript функционалности

- **FAQ Accordion** - разтваряне/затваряне на въпроси
- **Smooth Scrolling** - плавно скролване към секции
- **Intersection Observer** - fade-in анимации
- **Parallax Effect** - паралакс ефект на hero секцията
- **Live Badge Animation** - пулсираща live индикация

## 🔧 Персонализация

### Промяна на цветовете

Редактирайте CSS променливите в `styles.css`:

```css
.logo-number {
    color: #00b4d8; /* Промени цвета тук */
}
```

### Добавяне на нови филми

Добавете нови `.movie-card` елементи в `index.html`:

```html
<div class="movie-card">
    <img src="images/movie.jpg" alt="Movie Title">
</div>
```

### Промяна на FAQ въпроси

Редактирайте `.faq-item` елементите в секция `.faq`.
